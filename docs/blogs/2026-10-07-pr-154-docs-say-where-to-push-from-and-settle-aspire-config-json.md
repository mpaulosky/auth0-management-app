# docs: Say where to push from, and settle aspire.config.json

- **Release tag:** `v0.0.74`
- **Source PR:** [#154](https://github.com/mpaulosky/Blazor-Server/pull/154)

## PR description

### Why

The pre-push hook gates the checked-out commit and refuses a tree with uncommitted or untracked files. `CLAUDE.md`
mentioned the clean tree but not the checked-out branch, so pushing a branch from the `main` checkout was refused,
then needed a stash-and-switch because of an untracked `aspire.config.json`.

### What changed

- `CLAUDE.md` Commands: push from a clean checkout of the branch being pushed, which is the branch's own worktree, or
  a temporary `git worktree add` for a branch without one, instead of stashing and switching in the main checkout.
- `CLAUDE.md` Project layout: `aspire.config.json` is the Aspire CLI's shared settings and is committed together with
  this repo's own AppHost, not before. The stray copy pointed at another repo's AppHost
  (`../Articles/src/AppHost/AppHost.csproj`), so it was deleted rather than ignored. `.gitignore` is Owned by the
  repo-ci-baseline Template, which already treats `aspire.config.json` as shared and ignores only `.aspire/`.

### Verification

- markdownlint passes on `CLAUDE.md`, and the pre-push gate passed.
- `git status` in the main checkout is clean with the stray file gone.

Fixes #152
