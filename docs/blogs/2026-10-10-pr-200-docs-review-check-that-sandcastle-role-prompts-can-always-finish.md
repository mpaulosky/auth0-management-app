# docs(review): Check that Sandcastle role prompts can always finish

- **Release tag:** `v0.0.95`
- **Source PR:** [#200](https://github.com/mpaulosky/Blazor-Server/pull/200)

## PR description

### Why

Sandcastle's reviewer approved #71 even though its role prompts contradicted each other in two places. Copilot caught
them later, on #148:

- The tester was exempt from writing tests for manual criteria, but could only output <code>&#60;promise&#62;COMPLETE&#60;&#47;promise&#62;</code>
  after committing failing tests. An issue with only manual criteria, or a re-run whose tests already existed, could
  never finish.
- The reviewer was told to add a test for every missing criterion, including the exempt ones.

Whether a prompt's instructions agree with each other is a judgement call that no lint can make, so it belongs in the
review checklist.

### What changed

- The code-review skill (`.claude/skills/code-review/SKILL.md`) has a new check, **Sandcastle role prompts can always
  finish**, for changes to `.sandcastle/*-prompt.md` or `.sandcastle/roles/`. The reviewer follows every case a prompt
  allows, including an exemption, a re-run whose work is already committed, and "nothing to do", and checks that each
  case can reach <code>&#60;promise&#62;COMPLETE&#60;&#47;promise&#62;</code>. It also flags any instruction that contradicts an exemption stated
  elsewhere in the same prompt or in another role's prompt.
- `.github/copilot-instructions.md` is regenerated from the skill, so Copilot's review applies the same check.
- New `.sandcastle/lib/code-review-skill.test.mts`: checks that the skill keeps both requirements, in a paragraph scoped
  to `.sandcastle/`.
- `.github/ci/gate-checks.sh` reruns the Sandcastle tests when anything under `.claude/skills/code-review` changes, so a
  PR that edits only the skill still runs that test.

### Verification

- Sandcastle's sandbox ran `scripts/gate.sh` after the build and again after its review, and it passed both times.
  That includes the Copilot review sync check and `pnpm run check:sandcastle`.
- The gate-trigger change was made after the first Claude review. The pre-push gate passed, and with the change it ran
  the Sandcastle check.

Closes #151
