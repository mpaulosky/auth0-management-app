# chore(baseline): Re-apply the repo-ci-baseline Template

- **Release tag:** `v0.0.33`
- **Source PR:** [#111](https://github.com/mpaulosky/auth0-management-app/pull/111)

## PR description

### Why

The repo-ci-baseline Template changed, so this re-Applies it. The new Owned Sandcastle modules read names and files this repo's own Seed files didn't have yet, which failed the Sandcastle type-check and tests.

### What changed

- `da79f30`, `376ca0a`: the Template's Owned files (workflows, scripts, hooks, `.sandcastle/` modules and prompts, `docs/PROCESS.md` and so on), and the Sandcastle skills pinned to the Application Factory. These are reviewed in the Template, not here.
- The Seed files brought up to date:
  - `.sandcastle/lib/repo-config.mts` exports `GATE_LIMIT_MINUTES` (10, the Template default).
  - `.sandcastle/roles/skills.md` holds the `# SKILLS` block the prompts take as <code>&#123;&#123;REPO&#95;SKILLS&#125;&#125;</code>.
  - `.sandcastle/check-paths.txt` lists the files `check.sh` no longer hard-codes.
  - `.sandcastle/roles/shared-rules.md` gains the "UI developer" section the `ui` role needs, with the UI files named by kind.
- `repo-config.test.mts` and `role-prompts.test.mts` follow the new Owned prompts and `check.sh`. A new test requires every `CHECK_PATHS` entry to be watched, so a changed file can't skip the Sandcastle check.
- `check-paths.txt` holds plain paths and `:(glob)` lines only, and a test refuses any other line starting with `:` (an exclude would trim what the others watch). This answers a Copilot thread.
- `docs/plans/sandcastle-workflow.md` says 12 hours for the `sandcastle:building` label age, as `BUILDING_LABEL_MAX_AGE_MS` does. This answers a Copilot thread.

### Verification

- `scripts/gate.sh` passes, including the local review (two runs, 4 rounds each; the last has one Advisory finding open for a follow-up). `pnpm run check:sandcastle` passes with 3913 tests.
- The review focused on the Seed files, since the Owned files are the Template's.
- Mutation checks: dropping the `.claude/skills`, `.github/scripts` or tests-glob line from `check-paths.txt` fails the new test.
- `scripts/gate.sh` took 123 s warm locally.
