- **Release tag:** `v0.0.2`

## PR description

### Why

Dependabot alert #3 (GHSA-r4xh-jqrq-34v2, medium) flags `smol-toml` 1.8.0: `parse()` takes quadratic time because `parseKey` rescans to the end of the document on each key line. It comes in only as a development dependency of `markdownlint-cli2`. Version 0.23.3, the latest, pins `smol-toml` to exactly 1.8.0, so Dependabot can't raise it and there's no newer `markdownlint-cli2` to move to.

### What changed

- `pnpm-workspace.yaml` gets a pnpm `overrides` entry, `smol-toml: ^1.9.0`, with a comment to drop it once `markdownlint-cli2` depends on a fixed version.
- `pnpm-lock.yaml` now resolves `smol-toml` 1.9.1, the only change in the lock.
