# docs(ui): Add the UI restyle spec and its coding-standard lines

- **Release tag:** `v0.0.139`
- **Source PR:** [#310](https://github.com/mpaulosky/Blazor-Server/pull/310)

## PR description

### Why

The restyle map ([Map: Restyle the Generated App after the Articles look](https://github.com/mpaulosky/Blazor-Server/issues/303)) has settled every decision the restyle
needs. Sandcastle builds from issues that point at a spec, so the decisions need one document that says what to build.

### What changed

- **`docs/plans/ui-restyle.md`**, the visual spec. It covers:
  - **Tokens:** the combined `@custom-variant dark` that follows the OS now and a server-rendered `data-theme` later, the blue `--color-accent-*` `@theme` block the
    Palette can rebind, and `ApplicationConstants.AppName` as the one brand value.
  - **Shared components:** Card, PageHeader, StatTile, Badge and Button in `Components/Shared/`, with their parameters and class lists.
  - **Layout:** the page shell, the nav with a <code>&#60;details&#62;</code> menu below `md`, `LoginDisplay`, the new footer, the error bar and the reconnect modal.
  - **Pages:** Home, Profile, Admin, Access Denied, Not Found and Error.
  - **Tests** and the seven **implementation issues** in build order.

  Two choices differ from the map's tickets, each to fit a repo rule:
  - **Home's Log in button links to `profile`**, so the cookie challenge takes a Visitor through Auth0. That keeps Home from depending on the Authentication slice.
  - **The Hero card's two-column grid comes from Home's `Class`**, not from the card itself, so the one-column error panels don't get an empty column.
- **`docs/CODING_STANDARDS.md`** and **`.claude/rules/blazor.md`** gain the rules the builders follow:
  - Style every surface for light and dark with `dark:`.
  - Write accent colour as `accent-*`, never as a raw hue.
  - `Components/Shared/` holds UI building blocks only. It isn't the Shared Kernel, and it never depends on a feature slice.

No code changes. The class lists come from the prototype branch `chore/prototype-ui-restyle`, which was checked in headless Chromium in light, dark and with the Rose Palette.
