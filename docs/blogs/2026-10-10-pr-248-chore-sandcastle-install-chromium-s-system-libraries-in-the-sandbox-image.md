# chore(sandcastle): Install Chromium's system libraries in the sandbox image

- **Release tag:** `v0.0.114`
- **Source PR:** [#248](https://github.com/mpaulosky/Blazor-Server/pull/248)

## PR description

Closes #245

### Why

`scripts/gate.sh` runs every test project, so once the Playwright E2E tests from #247 exist, the sandbox's gate has
to launch Chromium. The sandbox image had neither Chromium nor the system libraries it needs, so #247 could never
pass its own gate. This change is built by hand because Sandcastle builds its image from `main` and its sandbox has
no Docker to check an image change.

### What changed

- `.sandcastle/Dockerfile` runs <code>pnpm dlx playwright&#64;&#36;&#123;PLAYWRIGHT&#95;VERSION&#125; install&#45;deps chromium</code> as root, after
  `corepack enable pnpm` and before the switch to the agent user. `PLAYWRIGHT_VERSION` is an `ARG` set to 1.63.0,
  the `Microsoft.Playwright` version in `Directory.Packages.props`.
- The step then removes root's pnpm caches and the apt lists, so they don't stay in the layer.
- Only the libraries go into the image. The E2E fixture (#247) downloads the browser at test time, at whatever
  `Microsoft.Playwright` version is pinned then, so a Playwright bump doesn't need an image change. The comment in
  the Dockerfile says so.
- `lib/dockerfile.test.mts` is unchanged. Its checks pin the linter versions that `gate.sh` and the image must
  share. A test tying `PLAYWRIGHT_VERSION` to `Directory.Packages.props` would fail on every Dependabot bump,
  which is the image churn this design avoids. The ARG only has to move if a later Chromium needs a library this
  version doesn't install.

### Verification

- The image builds the way Sandcastle builds it:
  `docker build -t sandcastle-245-verify --build-arg AGENT_UID=$(id -u) --build-arg AGENT_GID=$(id -g) .sandcastle`
  completed with exit code 0. The install-deps step resolved `playwright 1.63.0` and installed Chromium's apt
  packages (`libxcb-dri3-0`, `libwayland-server0`, `libx11-xcb1` and others).
- In a container from that image, running as the agent user (`uid=1001(agent)`), with no extra privileges:
  - `pnpm dlx playwright@1.63.0 install chromium` printed
    `Chrome Headless Shell 153.0.8010.12 (playwright chromium-headless-shell v1243) downloaded to /home/agent/.cache/ms-playwright/chromium_headless_shell-1243`.
  - A Node script using `playwright@1.63.0` ran <code>chromium&#46;launch&#40;&#123; headless&#58; true &#125;&#41;</code> and opened `about:blank`. It
    printed `chromium 153.0.8010.12 opened about:blank`.
- `pnpm run check:sandcastle` passed (803 tests).
- `scripts/gate.sh` passed, and the pre-push hook ran it again on push.
