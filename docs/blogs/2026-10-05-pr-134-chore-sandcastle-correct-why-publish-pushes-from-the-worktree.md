# chore(sandcastle): Correct why publish() pushes from the worktree

- **Release tag:** `v0.0.67`
- **Source PR:** [#134](https://github.com/mpaulosky/Blazor-Server/pull/134)

## PR description

### Why

The comment above `publish()` in `.sandcastle/lib/build.mts` said the pre-push hook "checks the checked-out branch's name". The hook doesn't work that way. It gates the refs being pushed (`.github/hooks/pre-push:37-38`). It refuses a push whose commit isn't the checkout's `HEAD`, because its gate tests the working tree (`:56-64`). Copilot found the same wrong rationale in the dotfiles Sandcastle guide (mpaulosky/dotfiles#61, corrected in #62).
