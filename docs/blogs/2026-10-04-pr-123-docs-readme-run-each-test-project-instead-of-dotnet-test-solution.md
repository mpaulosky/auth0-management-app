# docs(README): Run each test project instead of dotnet test --solution

- **Release tag:** `v0.0.62`

## PR description

Before: step 3 of the README setup said to run `dotnet test --solution Blazor-Server.slnx`. Under Microsoft Testing Platform a solution-level run can report "Zero tests ran" even when every project passes, which is why `scripts/gate.sh` and CI test one project at a time.

After: step 3 loops over each project under `tests/` with `dotnet test --project`, stops at the first failing project, and says why the solution-level command isn't used.

`docs/README.md` isn't edited here; `sync-readme.yml` copies it over after merge.

Verified locally: the loop runs both test projects (4 and 29 tests pass), markdownlint is clean, and `scripts/gate.sh` passed on push.
