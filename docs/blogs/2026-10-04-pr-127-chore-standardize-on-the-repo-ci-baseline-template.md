# chore: Standardize on the repo-ci-baseline Template

- **Release tag:** `v0.0.64`
- **Source PR:** [#127](https://github.com/mpaulosky/Blazor-Server/pull/127)

## PR description

Brings Blazor-Server onto the shared CI, release, hook and lint Baseline from the `repo-ci-baseline` Template in dotfiles. This repo's local fixes went into the Template first, in dotfiles#20 and dotfiles#21, so the Apply keeps them:

- the Copilot review cap (#119);
- the `sandcastle:needs-human` hold (#94);
- the Sandcastle pre-push gate skip (#93);
- the `.sandcastle/.env` deny.

### Change

- **Apply** (`1d2128c`): exactly the output of `apply.sh`. Owned files are replaced, and the Seed files `prepare.sh`, `coverage-threshold` (80), `gate-checks.sh` and the issue templates are added.
- **Gate checks:** the Copilot review sync and Sandcastle TypeScript checks move into `.github/ci/gate-checks.sh`, so they still run in pre-push and in the Sandcastle sandbox. The review sync CI job leaves `lint-markdown.yml` for its own `copilot-review-sync.yml`.
- **Removed:** `sync-readme.yml`, because `release_post.py` already copies the README, and `scripts/tests/gate.test.sh`, which tested the old gate.
- **`tests/.editorconfig`** keeps the test analyzer suppressions. Without them the build fails with 20 CA1707 errors under the Template's root `.editorconfig`.
- **Markdown:**
  - the vendored `dotnet-*` skills are ignored through a nested config;
  - the Sandcastle prompts keep their inline HTML;
  - the tables are fixed;
  - the pre-commit hook now honours nested configs.
- **Docs:**
  - `docs/index.html` styles the blog cards `release_post.py` now writes;
  - SECURITY and REFERENCES no longer say AINotesApp;
  - CONTRIBUTING targets `main`, not `develop`;
  - CLAUDE.md and README list the `fix/` branch prefix and `gate-checks.sh`.

### Behaviour changes

- **The test job is now `Test Suite`, replacing `Test Report Summary`.** CodeQL skips docs-only PRs, so `Analyze (csharp)` can't stay a required check. I'll update the ruleset in the same sitting as the merge.
- **The coverage threshold of 80 is now enforced** (it used to only warn). Coverage is currently 100%.
- **CI no longer passes the 13 `AUTH0_*` variables.** No such secrets exist, and nothing reads them.
- **`code-metrics.yml` is manual only**, per the Template.
