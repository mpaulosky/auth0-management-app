# fix(nav): Make the Home link base-relative

- **Release tag:** `v0.0.135`
- **Source PR:** [#295](https://github.com/mpaulosky/Blazor-Server/pull/295)

## PR description

### Why

The Home `NavLink` pointed at `/`. When the Generated App is hosted under a non-root base path (for example `/app/`), that link leaves the app for the host's root. The brand, Profile and Admin links are already base-relative. This was a follow-up from #288.

### What changed

- `NavMenu.razor`: the Home `NavLink`'s `href` is now `""`, which resolves against <code>&#60;base href&#62;</code>. `NavLinkMatch.All` still marks it active on the app's root.
- `NavMenuTests` and `MainLayoutTests`: the Home link tests find the link by its text and check that its `href` is empty. They no longer look for <code>a&#91;href&#61;&#39;&#47;&#39;&#93;</code>.

### Verification

- The new `NavMenuTests.Render_HomeLink_IsBaseRelative` failed before the change (`found "/"`) and passes after it.
- `UI.Tests.Unit`: 59 passed. The pre-push gate passed.
