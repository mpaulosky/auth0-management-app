### PR description

## Summary

Replaces the squad branch cleanup script and workflow with the fail-safe version from mpaulosky/Articles#238. Tracked in mpaulosky/Articles#240.

The copy merged earlier did nothing on GitHub's runner, because it only listed local branches. It also had unsafe paths for local `--apply` runs: ancestry of `main` counted as "merged", `gh` errors counted as "no PR", `--orphan-days` wasn't validated, and deletes weren't leased.

## Changes

- Looks at `origin/*` as well as local branches.
- Treats a branch as merged only when a merged PR contains every tip it deletes. Skips branches with an open PR, or with no commits of their own and no PR.
- Fails closed on `gh` or `git fetch` errors.
- Leases remote deletes on the checked tip, checks local tips before deleting, and keeps any branch whose worktree couldn't be removed.
- Validates and caps `--orphan-days`.
- Allows a manual `--apply` only from `main` (an accident guard, not a security boundary).
- Adds `scripts/squad/tests/cleanup-squad-branches.test.sh` and the **Squad Scripts Test** workflow.
