# docs: Grant the Management API application read:role_members

- **Release tag:** `v0.0.6`
- **Source PR:** [#26](https://github.com/mpaulosky/auth0-management-app/pull/26)

## PR description

### Why

The SDK research in [#23](https://github.com/mpaulosky/auth0-management-app/pull/23) found that Auth0's reference lists `read:role_members` for two calls the feature makes: listing a User's Roles (<code>GET &#47;users&#47;&#123;id&#125;&#47;roles</code>) and listing a Role's Users (<code>GET &#47;roles&#47;&#123;id&#125;&#47;users</code>). Without the permission, the Machine to Machine application can't make those calls, and the docs listed only six permissions.

### What changed

- `CLAUDE.md` adds `read:role_members` to the permissions the Machine to Machine application is granted.
- `README.md`'s permission table adds a `read:role_members` row. The `read:users` row no longer says it reads a User's Roles.
