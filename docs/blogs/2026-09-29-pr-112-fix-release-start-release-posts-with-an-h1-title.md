# fix(release): Start release posts with an H1 title

- **Release tag:** `v0.0.58`
- **Source PR:** [#112](https://github.com/mpaulosky/Blazor-Server/pull/112)

## PR description

The repo's Markdown rules (`.github/instructions/markdown.instructions.md`) say every document starts with one H1 and never skips a heading level. `render_post` wrote the post title as an H2, so every generated release post broke the rule.

Generated posts now use:
- `#` for the title;
- `##` for Summary, PR description, Commits and Files changed;
- `###` for the file areas.

Existing posts aren't rewritten. This is the same fix as mpaulosky/atelier-store#64.

## Tests

- A new test checks that a rendered post has exactly one H1 and never skips a level. It failed before the change.
- Existing expectations for generated posts move up one level.
