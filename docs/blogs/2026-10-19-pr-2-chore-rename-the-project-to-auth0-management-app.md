# chore: Rename the project to Auth0 Management App

- **Release tag:** `v0.0.1`
- **Source PR:** [#2](https://github.com/mpaulosky/auth0-management-app/pull/2)

## PR description

### Why

The repo was seeded as "Blazor Server Template" and still carried that name, plus the release history of the project it was copied from. It is now Auth0 Management App.

### What changed

- Prose titles (`CONTEXT.md`, both READMEs, `docs/index.html`), the displayed `ApplicationConstants.AppName` and its test now read "Auth0 Management App". The Template and Generated App terms are unchanged.
- `Blazor-Server.slnx` is now `Auth0ManagementApp.slnx`, with every reference updated (CLAUDE.md, README, Sandcastle rules and its test). The `Solution Name :` file headers say `Auth0ManagementApp`.
- `package.json` name is `auth0-management-app`; GitHub links point at `mpaulosky/auth0-management-app`.
- **Behaviour change:** the Auth0 role-claim default is now `https://auth0-management-app/roles` (was `https://blazor-server-template/roles`). An Auth0 Action deployed with the old namespace must be updated.
- The inherited release history is cleared: the 161 generated blog posts are deleted, and the release tables and blog index are emptied, ready for this project's first Release.

### Verification

- `dotnet build Auth0ManagementApp.slnx`: 0 warnings, 0 errors.
- Domain, Architecture, UI unit and UI integration tests pass; `pnpm run check:sandcastle` passes.
- The pre-push gate passed on push.
- AppHost and E2E tests were not run locally.
