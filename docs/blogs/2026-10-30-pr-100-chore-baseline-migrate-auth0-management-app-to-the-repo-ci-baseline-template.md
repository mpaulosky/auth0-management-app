# chore(baseline): Migrate auth0-management-app to the repo-ci-baseline Template

- **Release tag:** `v0.0.31`
- **Source PR:** [#100](https://github.com/mpaulosky/auth0-management-app/pull/100)

## PR description

### Why

Moves auth0-management-app onto the repo-ci-baseline Template, so its CI, release, git-hook and Sandcastle files come from one source. Part of the Template rollout.

### What changed

- Ran `apply.sh`: the Owned files are the Template's, the Seed files were written once.
- Filled `.sandcastle/lib/repo-config.mts` from the old `config.mts` (roles, skills, gate-covered checks, check paths); the `ui` role stays on.
- Rebuilt `main.test.mts`, `gate-checks.sh` and `check.sh` on the Template's versions, keeping the repo's own checks. Added tests that pin every prompt's placeholders, `GATE_COVERED_CHECKS` and `CHECK_PATHS` to the files they describe, and `sandcastle-skills.txt` to `SANDBOX_SKILLS`.
- Pinned the six dotnet skills in `.github/ci/sandcastle-skills.txt` to the dotfiles commit the old workflow used (`8dc86df`). That pin is a decision for the owner: the skills become the agents' instructions.
- Updated `CLAUDE.md`, `.claude/rules/baseline.md`, `.sandcastle/CODING_STANDARDS.md` and `docs/plans/sandcastle-workflow.md` to the Template's workflow.
- Kept the repo's own `docs/adr`, `docs/plans`, `.claude/rules` and `.claude/settings.json`.

### Lost or left alone

- The Template's `sandcastle.yml` has no follow-up-only job: the `mode` job and the `SANDCASTLE_FOLLOW_UP_JOB` and `SANDCASTLE_FOLLOW_UP_LABEL` variables are gone, and so are the "follow-up run ends red" check and the host's auto-labelling of `review:claude`.
- Deleted `gate-checks.test.mts` and `watch-pr.test.mts`: the Template's `check_gh_repo.py` and `scripts/tests/watch-pr.test.sh` cover them.
- The Dockerfile is unchanged: it is still bookworm with the Playwright libraries installed unconditionally, unlike the Template's trixie and `INSTALL_*` version. The role prompts keep their minor differences from the Seed.

### Verification

- `scripts/gate.sh` passes: markdown, YAML, workflow and shell lints, the build, and every test project.
- `pnpm run check:sandcastle` passes.
- Local review (`/pre-push-review`): 6 rounds, nothing blocking.

Fixes mpaulosky/dotfiles#319

Follow-ups: #101 (Advisory review finding R27), and on dotfiles mpaulosky/dotfiles#368, mpaulosky/dotfiles#369 and mpaulosky/dotfiles#370 (the three Claude Review threads on this PR that concern the Template).
