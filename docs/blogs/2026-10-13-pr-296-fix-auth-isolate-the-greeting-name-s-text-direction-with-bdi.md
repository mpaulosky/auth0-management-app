# fix(auth): Isolate the greeting name's text direction with bdi

- **Release tag:** `v0.0.136`
- **Source PR:** [#296](https://github.com/mpaulosky/Blazor-Server/pull/296)

## PR description

### Why

The nav bar greets a signed-in User as "Welcome! {name}", and the name comes from their Auth0 profile. A right-to-left name, such as one in Arabic or Hebrew, can make the browser's bidirectional algorithm reorder the "Welcome!" around it. This was declined as out of scope in #287 and offered as its own change.

### What changed

- `LoginDisplay.razor`: the greeting name is wrapped in <code>&#60;bdi&#62;</code>, which isolates its text direction from "Welcome!". The Razor comment explains why.
- `LoginDisplayTests`:
  - The greeting tests now check the greeting span's text instead of searching the raw markup for "Welcome! {name}".
  - The new theory `Render_User_NameClaimSet_IsolatesTheNamesTextDirection` checks that a left-to-right name and a right-to-left name each sit in the <code>&#60;bdi&#62;</code>.
- `NavBarTests` (integration): the served HTML now holds <code>Welcome&#33; &#60;bdi&#62;a&#45;user&#60;&#47;bdi&#62;</code>.

### Verification

- The new theory and the updated integration test failed before the markup change and pass after it.
- `UI.Tests.Unit`: 61 passed. `UI.Tests.Integration`: 57 passed. The pre-push gate passed.
