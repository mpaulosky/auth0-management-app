# feat(UI): Show the favicon before the app name in the nav bar

- **Release tag:** `v0.0.126`
- **Source PR:** [#272](https://github.com/mpaulosky/Blazor-Server/pull/272)

## PR description

### Why

The nav bar's brand link was the text "UI" on its own. Showing the app's favicon next to it gives the Generated App a
recognisable mark in the header, the same one the browser tab already shows.

### What changed

- `NavMenu.razor`: the brand link now starts with the favicon (`favicon.png`, 32px) followed by "UI", laid out with
  Tailwind utilities (`flex items-center gap-2`, `h-8 w-8`). The image has an empty `alt` because the link's text
  already names it.
- `wwwroot/favicon.png`: replaced with a 512x512 image, so it stays sharp at the nav bar's size and in the browser tab.
- `NavMenuTests.cs`: a new bUnit test, `Render_BrandLink_ShowsFaviconBeforeName`, checks the link's content in order:
  an `img` pointing at `favicon.png`, then the text "UI". It compares child nodes rather than using `img:first-child`,
  which counts only elements and so would pass with the icon on either side of the name.

### Verification

- The new test failed before the markup change and passes after it, and it fails if the icon is moved after "UI".
- `scripts/gate.sh` passes: the Release build and every test project, including the Playwright E2E tests.
- Previewed locally with `dotnet run --project src/UI`: the favicon shows to the left of "UI" in the nav bar.
