## ci(code-metrics): Grant write access and open the metrics PR with the PAT

- **Release tag:** `v0.0.36`
- **Source PR:** [#37](https://github.com/mpaulosky/Blazor-Server/pull/37)

### PR description

`.NET code metrics` has failed on every push to main. The repository's default `GITHUB_TOKEN` is read-only (`default_workflow_permissions: read`) and the workflow had no `permissions:` block, so `create-pull-request` got a 403 pushing `create-pull-request/patch`.

## Changes
- **`permissions:`** grants `contents: write` and `pull-requests: write`.
- **`token:`** is `RELEASE_PR_PAT || GITHUB_TOKEN`, the same fallback `release.yml` uses. A PR opened with `GITHUB_TOKEN` doesn't trigger `pull_request` workflows, so main's required checks would never report and the metrics PR could never merge. The repo's "Allow GitHub Actions to create and approve pull requests" setting is also off, so `GITHUB_TOKEN` alone couldn't open the PR at all.
- **`branch: chore/code-metrics`** replaces the default `create-pull-request/patch` so the bot follows the repo's branch naming.
