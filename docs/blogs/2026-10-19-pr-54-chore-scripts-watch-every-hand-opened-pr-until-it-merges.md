# chore(scripts): Watch every hand-opened PR until it merges

- **Release tag:** `v0.0.15`
- **Source PR:** [#54](https://github.com/mpaulosky/auth0-management-app/pull/54)

## PR description

### Why

Hand-opened PRs sat with unresolved review threads, and PR Auto-Merge holds a PR on every unresolved thread. Sandcastle's follow-up sweep acts only on the PRs Sandcastle opened itself (`isSandcastlePullRequest`), and a `chore/` branch never gets past the Sandcastle job's `if:`, so nothing answered those threads.

### What changed

- **<code>scripts&#47;watch&#45;pr&#46;sh &#60;n&#62;</code>** polls a PR every minute and exits with the reason it woke. The reasons are: the PR merged or closed; it conflicts with or is behind `main`; every check finished and one failed (an empty check list doesn't count as finished); an unresolved review thread's last comment isn't the session's; a changes-requested review, or a person's review body or PR comment, that it hasn't reported before; or nothing changed for 30 minutes. It tells the session's comments apart by a <code>&#60;&#33;&#45;&#45; claude&#45;session &#45;&#45;&#62;</code> marker rather than by login, because a local session posts with the owner's token. It keeps the IDs it reported in the git common dir, so a restart after a push doesn't report them again.
- **`CLAUDE.md`** tells the session that opens a PR to run the script in the background after opening it and after every push, and says how to act on each wake:
  - merge `main` in when the branch conflicts or is behind, and fix red checks;
  - on a thread it agrees with, fix the code, reply, and resolve the thread only if Claude Review or Copilot opened it;
  - on a thread it declines, reply and leave it open for the owner;
  - mark every comment it posts.

  The session stops when the PR merges or closes, when only a person or an unfixable check is holding it, or after 30 idle minutes, and says which.

Sandcastle's slow follow-ups on its own PRs, which wait behind a running build, are tracked separately in #53.
