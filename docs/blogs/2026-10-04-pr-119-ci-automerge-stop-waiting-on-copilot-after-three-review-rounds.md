# ci(automerge): Stop waiting on Copilot after three review rounds

- **Release tag:** `v0.0.61`
- **Source PR:** [#119](https://github.com/mpaulosky/Blazor-Server/pull/119)

## PR description

Before: `pr-automerge.yml` merged a PR only once Copilot had reviewed its exact head commit and every review thread was resolved. Copilot re-reviews every push and often finds something new, so each fix triggered another round, and a PR could chase its reviews forever (#118 got a fresh thread on each push).

After: once Copilot has reviewed **three distinct commits** of a PR (`COPILOT_REVIEW_CAP` at the top of the script), Copilot stops holding the merge:

- the merge no longer waits for Copilot's review of the latest commit;
- Copilot's unresolved threads no longer count (a thread's author is the author of its first comment).

Everything else still blocks at the cap: threads from people (or with no known author, such as a deleted account), required checks, conflicts, and the `sandcastle:needs-human` label. When the cap lets a PR through, the run log says so and how many Copilot threads it merged past, for example `Copilot review cap (3) reached on PR #7: merging past 2 unresolved Copilot thread(s).`

Trade-off: anything Copilot raises from round three on can merge without being looked at. Those threads stay on the merged PR to act on later. Below the cap, nothing changes.

How:

- `.github/workflows/pr-automerge.yml`: the GraphQL query now fetches each thread's first comment author; the check counts distinct reviewed commits and applies the cap.
- `.github/scripts/tests/pr-automerge.test.mjs`: 8 new tests (below the cap, at the cap, repeat reviews of one commit not counting, a person's thread still blocking, unknown author, checks still required). The 3 cap tests fail against the old workflow; 17/17 pass with the change.
- `docs/plans/sandcastle-workflow.md`: notes the exception next to "merges only once every thread is resolved".

Verified locally: `scripts/gate.sh` passed (YAML, Markdown and workflow lint, Release build, all test projects).
