## ci: Lint workflows and shell scripts before push and in CI

- **Release tag:** `v0.0.56`
- **Source PR:** [#110](https://github.com/mpaulosky/Blazor-Server/pull/110)

### PR description

Brings over the workflow and shell lint that atelier-store runs (mpaulosky/atelier-store#10), and fixes everything it found on `main`.

## New checks

- **`lint-actions.yml`** runs `actionlint`, `zizmor` (fails on medium or above) and `shellcheck`, all pinned.
- **`scripts/gate.sh`** adds workflow lint (actionlint, zizmor) and shell lint (shellcheck) on changed files, at the same pinned versions. Everything else about the gate is unchanged, including how it works with Sandcastle; the pre-push hook is untouched.
- **Gate tests:** they now stub the new tools and cover both steps. There are 18 tests, all passing.
- **New "Hook tests" CI job:** CI never ran the hook or gate tests. This job runs both.

## Fixes to what the linters found

- **Every action is pinned to a commit SHA.**
- **`ci.yml`:**
  - The default token is now read-only; only the report job can write.
  - Matrix values go through `env:` instead of being interpolated into scripts.
  - Checkouts no longer keep their credentials.
  - The summary step still fails the job when tests fail, because "Test Report Summary" is the required check.
- **`code-metrics.yml`:** the dispatch reason was interpolated straight into a shell script.
- **zizmor findings documented:** the `workflow_run` trigger in `pr-automerge.yml`, and the checkouts that push with their credential (`release`, `code-metrics`, `backfill-blog-posts`).
- **`pre-commit`:** `cd "$ROOT" || exit 1` (SC2164).

## `sync-readme.yml`: its PRs could never merge

It pushed with `GITHUB_TOKEN`, and its commit message carried the skip-CI marker, so `main`'s required checks never ran on the sync PR. It now:
- uses `RELEASE_PR_PAT`, as atelier-store does;
- leaves the marker out of the commit message;
- titles the PR `[skip-release]`, so a README sync doesn't produce a release blog of its own.

## Squad tooling removed

The squad branch-cleanup workflow and script are gone; this repo doesn't use Squad (see #7).

## Validation

- `actionlint`, `zizmor` (online audits included), `yamllint` and `shellcheck` are clean.
- Gate tests: 18 of 18. Pre-push hook tests: 20 of 20.
- The pre-push gate passed, running its new workflow and shell lint steps.

**Follow-up after merge:** make `actionlint`, `zizmor` and `shellcheck` required in the `main-rules` ruleset.
