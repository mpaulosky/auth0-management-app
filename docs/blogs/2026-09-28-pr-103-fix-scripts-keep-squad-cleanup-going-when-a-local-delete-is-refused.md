## fix(scripts): Keep squad cleanup going when a local delete is refused

- **Release tag:** `v0.0.53`

### PR description

## Summary

Syncs `scripts/squad/cleanup-squad-branches.sh` with mpaulosky/Articles#245. Refs mpaulosky/Articles#240.

Under `set -euo pipefail`, the first unmerged local orphan that `git branch -d` refused (when run without `--force-local`) made the whole run **exit 1**. It printed no message and never reached the remote deletions. Local `--apply` runs were broken; the nightly GitHub job, which has no local orphans, was not affected.

The delete command now runs as the `if` condition, so a refusal is reported and the run carries on.

## Tests
