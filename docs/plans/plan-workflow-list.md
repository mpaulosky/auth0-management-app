# Sandcastle Workflow

1. Get open labeled issues, review them, and create a plan using the Wayfinder skill. Rubber-duck the plan.
1. Implement the plan with the team, including as needed:
   - [ ] an Architect
   - [ ] a Backend Developer
   - [ ] a UI Developer
   - [ ] a Tester using TDD
   - [ ] a Scribe to document changes
1. Pre-push:
   - [ ] Lint Markdown files if created or modified
   - [ ] Lint YAML/yml files if created or modified
   - [ ] Build and test, resolving issues until both complete successfully
1. Commit and push to GitHub.
1. Create a PR.
1. Address GitHub review PR comments, suggestions, and merge conflicts.
1. Merge the PR and document.
